# Tepi Kata — Website Portofolio (Terpisah dari Aplikasi Studio)

Project ini dipisah dari repositori `tepikata.github.io` agar aplikasi Studio tim dan tautan galeri klien tetap aman dan tidak terganggu.

## Cara Publikasi ke GitHub Pages
1. Buat repositori baru (Public) di akun GitHub `tepikata`, misalnya bernama `portfolio`.
2. Unggah `index.html` dan folder `images/` ke branch `main`.
3. Buka **Settings → Pages** → pilih **Deploy from a branch** → branch `main` (`/ (root)`) → **Save**.
4. Website akan aktif di `https://tepikata.github.io/portfolio/`.

## Cara Mengganti Foto Asli Tepi Kata
Ganti file gambar di dalam folder `images/` dengan nama file yang sama:
- `images/hero.jpg` (foto utama)
- `images/resepsi.jpg` (galeri Akad & Resepsi)
- `images/mappacci.jpg` (galeri Adat & Mappacci)
- `images/prewedding.jpg` (galeri Prewedding)
- `images/filosofi.jpg` (potret vertikal bagian Filosofi)
- `images/tentang.jpg` (foto bagian Tentang Kami)
