Koneksi GitHub Repository

Token GitHub hanya disimpan di browser perangkat ini (localStorage) dan tidak pernah disimpan di kode repository.

Cara Membuat Token GitHub (1 Menit)
  1. Buka GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Klik Generate new token, beri nama mis. Tepi Kata Portfolio Editor.
  3. Di bagian Repository access, pilih Only select repositories → pilih tepikata/portfolio (JANGAN pilih repo lain).
  4. Di bagian Repository permissions, ubah Contents menjadi Read and write.
  5. Klik Generate token, lalu salin dan tempel tokennya ke kolom di atas.
